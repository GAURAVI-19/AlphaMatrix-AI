# Architecture Documentation
## AlphaMatrix 8-Layer Responsible AI System Architecture

AlphaMatrix implements an enterprise 8-layer responsible decision architecture to ensure fairness, transparency, accountability, and security across multi-domain environments.

```
===========================================================================
  LAYER 1: MULTI-DOMAIN DATA INGESTION & FEATURE VECTOR MAPPING
  Ingests raw metric payloads across HR, Clinical, Finance, Industry & Edu.
===========================================================================
                                    │
                                    ▼
===========================================================================
  LAYER 2: PARAMETER TUNING & DYNAMIC MATRIX INJECTION
  Glassmorphic sliders allowing real-time parameter tuning overrides.
===========================================================================
                                    │
                                    ▼
===========================================================================
  LAYER 3: DYNAMIC MULTI-MODEL PREDICTION INFERENCE ENGINE
  FastAPI XGBoost microservice & local fallback heuristic models.
===========================================================================
                                    │
                                    ▼
===========================================================================
  LAYER 4: EXPLAINABLE AI (SHAP & LIME ATTRIBUTION MATRIX)
  Computes Waterfall steps, Force plots, and Feature Importance vectors.
===========================================================================
                                    │
                                    ▼
===========================================================================
  LAYER 5: ETHICAL AI FIREWALL & GUARDRAIL INTERDICTION
  Evaluates Demographic Parity & interdicts predictions (Risk >= 70%).
===========================================================================
                                    │
                                    ▼
===========================================================================
  LAYER 6: HUMAN-IN-THE-LOOP (HIP) GOVERNANCE QUEUE
  Managerial queue routing flagged predictions for review & sign-off.
===========================================================================

                                    ▼
===========================================================================
  LAYER 7: IMMUTABLE SECURITY AUDIT LOGS & DECISION CERTIFICATES
  Cryptographic audit logs, CSV exports, & ISO Decision Certificate PDFs.

  RBAC dashboards, LMS course enrollment, PIP cards, & Lavender theme.
```

---

### Layer Specifications

1. **Layer 1 (Multi-Domain Ingestion)**: Standardizes parameters from disparate sources (HR, Clinical, Finance) into normalized vector fields.
2. **Layer 2 (Parameter Injections)**: Intercepts baseline values and allows interactive sliding tuning on `AIInsights.jsx`.
3. **Layer 3 (Prediction Inference)**: Calculates risk scores, confidence intervals, and risk level tiers (`LOW`, `MEDIUM`, `HIGH`, `CRITICAL`).
4. **Layer 4 (Explainability SHAP/LIME)**: Deconstructs predictions into individual signed impact feature weights (`+` risk driver vs `-` protective factor).
5. **Layer 5 (Ethical Firewall)**: Intercepts high-risk decisions (Score >= 70%) to prevent automated unfair outcomes.
6. **Layer 6 (Human Governance)**: Requires manager review comments before high-risk decisions can take effect.
7. **Layer 7 (Auditability & Verification)**: Persists immutable audit logs in MongoDB and generates printable ISO Decision Certificates.
8. **Layer 8 (Enterprise Experience)**: Provides responsive glassmorphic UI styled with the **Lavender / Purple** brand design palette.
